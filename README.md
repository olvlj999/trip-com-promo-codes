# trip.com promo code: which codes still work for hotels, flights and car rentals, and how to stack cashback on top

You came for a code. Fine. The trouble with nearly every "Trip.com promo code" page is that it hands you a string of letters with no gate attached, so you paste it in at checkout, Trip.com shrugs, and you pay full price anyway.

Almost every code that works on Trip.com right now is welded to two things: **a specific payment card**, and **a designated campaign page you have to walk in through**. Miss either and the code is decoration. So the useful question isn't "what's the code" — it's "which code matches the card in my wallet, and is it still inside its validity window".

Here's what's live, what each one actually takes off, and where a cashback layer covers the bookings no code can touch.

## Why Trip.com rejects your code (four rules that decide everything)

Before the list, the mechanics. These come from the campaign terms Trip.com publishes with its bank and card partners, and they explain the vast majority of "the code didn't work" complaints.

**You must enter through the campaign page.** Trip.com's partner terms are blunt about this. Bookings made by going straight to the site — even with the right code saved in your account — don't qualify.

**The card has to be the one named in the terms.** A Visa campaign needs a Visa card from the participating issuer, settled in the right currency. Samsung Visa's Korean campaign only pays out on USD transactions; KTC's Thai hotel code only works on bookings paid in baht.

**One code per order.** Every campaign repeats some version of "each order can be applied with one promo code only", and the discounts explicitly don't combine with Trip Coins, gift cards or other offers.

**Stock is finite.** Codes are issued first come, first served, and campaigns can close early if the budget runs out. A code can be perfectly valid and still be used up for the week — KTC's version caps redemptions at 40 per week, and Bank Jago's Indonesian promo runs for the first 1,000 transactions each month.

> Trip.com's own booking tips for partner campaigns add one more: don't open other sites, ads or push notifications while you're booking. Wandering off the campaign flow mid-checkout is enough to break the tracking.

## How to actually apply a code without losing it

1. Log into your Trip.com account before anything else. Guest checkout doesn't qualify.
2. Get to Trip.com through the link printed in your bank's or card partner's terms — not by typing the address into a fresh tab.
3. Search and pick your hotel, flight or car. For hotels, only prepaid room types on eligible properties count; "Pay at Hotel" bookings and ticket+hotel bundles are excluded.
4. Apply the code at the customer-information step **before** the final payment screen, then confirm it shows as accepted. JCB's terms specifically tell you to enter it at that stage rather than at checkout.
5. Pay with the qualifying card, in the currency the terms require, without leaving the flow.

If a booking fails, is cancelled, or goes unpaid past the payment window, Trip.com returns the code to your account — it isn't burned, as long as stock remains. Changing a booking, though, typically voids the code in that order.

## Quick answers to the questions that come up most

**Do codes work on flights?** Yes, but they apply to adult fares only, never to taxes and surcharges, and not to infant, child or student tickets.

**Any code for China domestic flights?** No. Campaign terms exclude them, along with ticket+hotel packages and properties from third-party sources.

**Can I use a code with Trip Coins?** No. Trip Coins, gift cards and other offers are excluded alongside promo codes.

**Can I use two codes?** No — one per order, across every campaign reviewed here.

**I cancelled — is my code gone?** It goes back to your account and can be reused while the campaign is live, assuming stock.

**Why does the discount look smaller than advertised?** Because of the tax treatment, the per-booking cap, or because you're the wrong card tier. The Mastercard programme, for instance, drops from 20% for World Elite cards to 10% for Platinum, with different minimum spends on each.
